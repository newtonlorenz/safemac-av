# Code of Conduct

## Our standard

We want participation in ClamAV GUI to be safe, useful, and welcoming. Contributors and maintainers are expected to:

- communicate with empathy, patience, and respect;
- critique ideas and code without attacking people;
- welcome different backgrounds, identities, and levels of experience;
- protect private or security-sensitive information; and
- accept responsibility, apologize, and repair harm when mistakes happen.

Harassment, threats, discriminatory language, sexualized attention, doxxing, sustained disruption, and publishing another person's private information are not acceptable.

## Scope

This standard applies in repository discussions, issues, pull requests, code review, release coordination, and public spaces where someone is representing the project.

## Enforcement

Maintainers may edit or remove contributions that violate this standard and may warn, temporarily restrict, or permanently ban participants when necessary. Enforcement decisions should be proportionate, documented privately where possible, and focused on community safety.

To report conduct privately, contact the repository owner through their GitHub profile. If no private maintainer channel is available, use GitHub's blocking and [content reporting](https://support.github.com/contact/report-content) tools. Do not publish personal or sensitive details in an issue.

Retaliation against a person who raises a good-faith concern is itself a violation.

## Attribution

This policy draws on the principles of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html) and is intentionally shortened for this project.
